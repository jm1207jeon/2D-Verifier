# 전체 검토 보고: 예외 상황 강건성 + UI/UX/HFE (2026-09)

대상: UDI Capture_ver.1 (WPF, .NET 8) 전체 소스. 검토 관점은 (1) 예외적인 운영 상황에서 오류·데이터
오염이 생길 수 있는 경로, (2) IEC 62366-1 관점의 사용 오류(use error) 유발 요소.
"검사 보조 도구" 결정(U-2)에 맞춰, 조치는 **잘못된 기록이 정상처럼 보이는 것**을 막는 데 우선을 두었다.

## 1. 수정 완료 (코드 반영)

### 1-1. 데이터 무결성 (가장 중요)
| # | 상황 | 이전 동작 | 수정 |
|---|---|---|---|
| D1 | 이미지 수신 대기 중 다음 라벨을 스캔 | `_pendingScan`이 덮어써져 **앞 사진이 뒤 바코드 이름으로 저장** | 촬영 예약 큐(최대 20건) - 앞 촬영 완료/실패/타임아웃 후 순서대로 촬영 |
| D2 | 멀티 탭 사진 저장 중 연속 판독 | 촬영 중이면 **소리 없이 사진 생략** | 예약 큐 + 8초 타임아웃 타이머로 누락 없이 순차 촬영, 누락 시 상태바 오류 표시 |
| D3 | 잘못된 날짜(13월, 32일 등) | `2025-13-45`처럼 정상 값으로 표시 | 달력 범위 밖이면 원문 6자리 그대로 표시(변환 안 함) |
| D4 | 확인 대화상자가 떠 있는 중 스캔 | 웨지가 대화상자에 값+**Enter를 입력 → '예'가 눌려 삭제 실행** 가능 | 대화상자 중 스캔 보류 + 기본 버튼 '아니오' |
| D5 | 빈 판독값(제어문자만) | 빈 행이 목록에 추가되고 Enter만 입력됨 | 무시 + 경고 |
| D6 | CSV에 식별 정보 없는 줄(엑셀 합계 행 등) | 키 `"|"`인 유령 행 생성 | 건너뛰고 건수 보고 |
| D7 | LOT 값이 `..`, `CON`, 끝이 `.` | 상위 폴더로 이탈하거나 폴더 생성 실패 | `SanitizeFolderName`으로 보정 |
| D8 | SN/QTY 헤더 정렬 | 문자열 정렬로 1,10,11,2… | 숫자 정렬(`SnNum`, `Qty:int`) |

### 1-2. 예외 처리 / 수명주기
- COM `ExecCommand`/`GetScanners` 예외(USB 분리, 드라이버 서비스 중지)를 서비스 안에서 흡수 → 호출 측은 "명령 실패"로만 인지, 앱 크래시 없음.
- `ActiveScanner` 조회를 lock 안에서 수행 (PnP 재열거 중 `IndexOutOfRange` 경쟁 제거).
- 배경 `Task.Run` 전부 try/catch + 로그 (촬영 명령, 비프, 트리거 해제, 강제 스캔 재무장).
- `OnBarcode`/`OnImage` 전체 try/catch → 예외가 전역 MessageBox로 튀지 않고 상태바 오류로 표시.
- 미리보기 디코드 실패(손상 이미지)해도 저장 흐름은 계속.
- `_closing` 플래그: 종료 시 스캐너 복원(디코드 모드/HID 키보드) 후 배경 재시도 루프가 다시 촬영 모드로 덮어쓰는 경쟁 제거.
- SNAPI 자동 전환 **세션당 최대 3회** → 전환은 성공하나 재연결 후에도 SNAPI가 아닌 기종에서 무한 재부팅 루프 방지.
- 설정 파일: 원자적 저장(임시 파일→교체), 손상/누락 항목 보정(`Normalize`), 저장 실패 시 1회 경고.
- 설정 자동 저장 디바운스(0.6초) - 경로 타이핑 중 글자마다 파일 쓰기 제거.
- 저장 경로 유효성 검사: 키보드 스캐너가 경로 입력란에 오입력해도 저장되지 않고 붉은 배경으로 경고.
- 이미지 저장 실패 원인별 메시지(권한 없음/디스크 부족/드라이브 미연결/경로 오류).
- 중복 실행 방지(Mutex) - 두 인스턴스가 스캔을 이중 처리·키보드 이중 입력하는 문제 차단.
- 전역 예외 핸들러 보강: UI 예외는 알리고 계속, 배경 작업/치명적 예외는 `%APPDATA%\ZebraScannerSuite\app.log`에 기록.
- SDK 미설치 PC에서 워치독이 10초마다 상태바를 "연동 불가"로 덮어쓰던 문제 → 1회만 표시.
- 키보드 웨지 차단(대상 프로그램이 관리자 권한) 감지 → 상태바 오류 안내.
- CSV 불러오기: 엑셀 ANSI(CP949) 저장본 자동 재시도, 파일 잠김(IOException) 안내.

### 1-3. UI/UX/HFE
- 상태바 메시지 3단계(정보/경고=갈색 굵게/오류=빨강 굵게) + 말줄임 + 툴팁으로 전체 보기.
- **목록 지우기** / **일반 탭 지우기** / **미저장 데이터가 있는 종료**: 건수·저장 여부를 보여주는 확인 대화상자 (기본 '아니오').
- 멀티 탭에 `● CSV 미저장` / `✓ CSV 저장됨` 표시 → 내보내기 유도.
- 일반 탭 실시간 목록 헤더에 건수 표시, 중복 스캔은 상태바에 "중복 스캔"으로 구분.
- [폴더 열기] 버튼 - 저장된 사진을 즉시 확인.
- 창 최소 크기(1024×600) + 작은 화면에서 작업 영역에 맞춰 자동 축소.
