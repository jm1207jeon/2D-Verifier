## 1. 목적 및 범위

본 문서는 사내 개발 소프트웨어 **UDI Capture_ver.1**을 품질검사 업무의 **보조 도구**로
사용하기 위한 평가·검증 활동과 그 결과를 기록한다. 본 도구는 UDI 바코드의 **판독값
파싱·화면 표시·참고용 파일 생성**을 수행하며, **품질기록의 원본을 생성하지 않는다.**

## 3. 용도 및 사용 범위 선언

- 본 도구는 **검사 보조 도구(inspection aid)** 로만 사용한다.
- 주 용도: ① UDI 바코드 판독값의 AI(응용식별자)별 파싱·화면 표시, ② 판독값의 엑셀 입력
  보조(키보드 웨지), ③ 라벨 사진의 참고용 보관, ④ 판독 목록의 참고용 CSV 생성.
- **품질기록 원본은 기존 승인된 절차/시스템(검사기록서, ERP 등)에 따라 생성**되며,
  본 도구의 출력(화면·CSV·사진)은 이를 대체하지 않는다.
- 작업자는 도구가 표시한 값을 **육안으로 확인한 후** 기록 시스템에 반영한다
  (도구 출력의 무확인 전기 금지).
- 도구 사용 불가 시(고장·미설치) 기존 수기 절차로 검사 업무 수행이 가능하다
  (업무 연속성에 필수적이지 않음).

## 8. 사용 조건 및 제한사항

1. 본 도구의 화면 표시값·CSV·사진은 **참고용**이며 품질기록 원본이 아니다.
2. 파싱 결과가 라벨 인쇄 내용과 다르다고 판단되는 경우 도구 값을 사용하지 않고
   육안 판독값을 기록하며, 해당 라벨 전문을 관리자에게 전달한다(테스트 케이스 추가).
3. 검증된 버전(§2 SHA-256)과 다른 버전을 임의 사용하지 않는다.
4. 이미지 캡처 기능은 SNAPI 지원 스캐너에서만 동작하며, 미지원 장비에서는
   바코드 판독 기능만 사용한다.
