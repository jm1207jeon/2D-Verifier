## V-02. 스캐너 연결

| # | 확인 내용 | 결과 | 비고 |
|---|---|---|---|

| 7 | MFG가 없는 라벨에서 MFG가 파란색(역산값)으로 표시되고, EXP−36개월+1일과 일치한다 | | |

## V-04. 키보드 입력(웨지)

| # | 확인 내용 | 결과 | 비고 |
|---|---|---|---|
| 1 | 엑셀 셀에 커서를 두고 스캔하면 판독값+Enter가 입력된다 | | |
| 2 | 입력된 값이 화면 표시값과 일치한다 | | |
| 3 | 연속 10회 스캔 동안 Caps Lock 상태가 변하지 않는다 | | |

## V-05. 중복 처리

| # | 확인 내용 | 결과 | 비고 |
|---|---|---|---|
| 1 | (일반 스캔, 중복값 무시 켬) 같은 라벨 재스캔 시 목록 행이 늘지 않고 기존 행이 하이라이트되며, 엑셀에 입력되지 않는다 | | |
| 2 | (멀티 스캔) 같은 라벨 재스캔 시 행 추가 없이 무음으로 처리되고, 신규 라벨은 비프가 울린다 | | |

## V-06. 사진 저장

| # | 확인 내용 | 결과 | 비고 |
|---|---|---|---|
| 1 | "바코드 리딩+이미지 캡처" 모드에서 스캔 시 사진이 저장되고 화면에 표시된다 | | |
| 2 | 날짜 폴더(YYYY-MM-DD)가 자동 생성되어 그 안에 저장된다 | | |
| 3 | (LOT 폴더 옵션 켬) LOT명 폴더 안에 저장된다 | | |
| 4 | 저장된 사진을 열어 라벨이 식별 가능한 품질인지 확인한다 | | |

## V-07. 멀티 스캔 집계

| # | 확인 내용 | 결과 | 비고 |
|---|---|---|---|
| 1 | 서로 다른 라벨 3종 스캔 시 고유 판독 수=3, 같은 LOT 2종이면 총 배치 수가 맞게 표시된다 | | |
| 2 | 가로 모드에서 같은 LOT의 시리얼이 한 행에 오름차순 콤마로 누적된다 | | |
| 3 | 헤더 클릭 정렬(오름→내림→해제) 및 같은 값 묶음 배경색이 동작한다 | | |
